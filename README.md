## KitaLearn
## A personalized math learning app that adapts to your age and location — powered by Google Gemini AI.

### How It Works

Sign in and enter your name, age, and location
Gemini AI generates a personalized math curriculum based on your profile and local education benchmarks
Work through structured chapters and questions at your own pace

### Features

Personalized curriculum — chapters and questions generated by Gemini based on age and location
Local benchmarks — content aligned to your country's math standards
Firebase Authentication — secure sign in and user management
Cloud storage — progress saved across sessions via Firestore

### Tech Stack

Flutter — cross-platform mobile frontend
Firebase Auth — authentication
Firestore — user data and progress storage
Google Gemini API — AI-generated curriculum and questions

### Getting Started
```git clone https://github.com/wz-Tan/kitahack_hackathon.git
cd kitahack_hackathon
flutter pub get
```
Set up your environment variables:
```cp .env.example .env```
# Fill in your Firebase and Gemini API keys
Then run:
```flutter run```
